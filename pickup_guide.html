Core Features

三大模組，完整解決
接車行政痛點

從每日點名到月份彙整，安親接車管理系統把老師過去手工的接車作業，全部數位化到手機上。

📋
今日接車點名

依年級、接送時間自動分組。一鍵標記接到 ✓ 或請假 ✗，支援備註與電話撥打，學校篩選快速定位。

📅
月份接車總表

整月接送狀況一張表呈現。上午接駛白色、下午接駛黃色、不接灰黑，奇偶週交替著色，一眼識別。

👥
學生資料管理

新增、編輯、刪除學生，設定安親 / 外生類型、接送天數與自訂時間。學校篩選、姓名搜尋即時過濾。

⚡
臨時加接

從名單選現有學生臨時換時間接送，或直接輸入名單外學生姓名。臨時記錄同步到月份總表，不漏接。

📞
一鍵撥打電話

點擊電話圖示即彈出家長號碼，點「撥打」直接打電話，免複製貼上。支援媽媽和爸爸兩組號碼。

🗓️
假日自動屏蔽

預載 2026 台灣國定假日，假日當天自動顯示提示，不顯示學生清單。可手動新增補課日或特殊假日。

📆
日期跨日切換

不只看今天，左右切換日期可查閱任意日期的點名記錄，方便補記或回溯確認接送情況。

⚙️
自訂接送時間

每位學生可單獨設定週一到週五的接送時間（午間 / 下午 / 不接），靈活處理社團日或特殊安排。

How It Works

四步驟上手，
今天就開始用

01
設定學生名單

在「學生管理」新增每位學生的姓名、年級、班級、聯絡電話，設定安親或外生類型與接送天數。

02
設定假日

前往「接車總表」的假日面板，確認國定假日清單並新增補課日或特殊假日。

03
每日手機點名

開啟今日點名頁，按學校篩選，依序點擊 ✓ 接到或 ✗ 請假，臨時加接直接輸入名字。

04
月底查閱總表

選擇月份產生接車總表，點擊格子可補錄或修改，支援列印留存紙本備份。
